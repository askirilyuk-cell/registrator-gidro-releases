# Регистратор гидроиспытаний — сборки

Здесь лежат только готовые сборки станции регистрации гидроиспытаний
(опрессовки) ПВО и устьевого оборудования. Исходный код в этом репозитории
не публикуется.

## Установка

Скачайте `RegistratorGidro.exe` из последнего релиза, положите в отдельную
папку и запустите. Установка не требуется: рядом с программой появится папка
`data` с базой и PDF-протоколами.

При первом запуске программа работает в демо-режиме с эмулятором датчиков —
железо для показа не нужно. Для реального измерительного модуля запускайте с
ключом `--real`, адрес и порт задаются на экране «Настройки».

## Обновление

Обновляться вручную не нужно: станция сама проверяет этот репозиторий при
запуске и предлагает поставить новую версию — «Настройки» → «Обновление
программы». База и протоколы при обновлении остаются на месте.
